# ParkEase

A responsive Parking Management System demo built with HTML5, CSS3, and modular ES6 JavaScript.

## Run

Serve this folder with any static server, for example:

```powershell
python -m http.server 4173
```

Open `http://localhost:4173/index.html`.

Demo user: `alex@demo.com` / `demo123`  
Demo admin: `admin@parkease.com` / `admin123`

Demo data is stored in browser LocalStorage and persists across refreshes.
